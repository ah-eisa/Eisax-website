Security

Scope: eisax.com and the public product access information below  ·  Updated: September 2026

This page separates controls observable on the EISAX corporate website from access information for individual products. Product services may use different controls; this page does not describe a shared security architecture.

Corporate website

eisax.com is a public, static information site. It does not require an account to read its pages. The site stores the selected display theme in your browser so that the preference remains available on later visits. See the Privacy Policy for the site's data-handling notice.

The live website is served over HTTPS and currently sends a Content Security Policy, HTTP Strict Transport Security, a referrer policy, and browser permission restrictions. These are website-delivery settings, not a claim about controls in other EISAX products.

Public product access

Access varies by product. The WealthGate AI public demo is read-only and uses synthetic data. This describes the public demo only, not a production WealthGate deployment.

The EISAX Agent interface is publicly accessible as part of EISAX Intelligence. Enterprise functionality may require controlled access. The public interface should not be treated as evidence that enterprise features are open to everyone.

Security questions and reports

For a security concern about this website or a listed product, use the existing EISAX contact address: partnerships@eisax.com. Include the affected URL and a concise description; do not include credentials or confidential client data in your first message.
