سياسة الخصوصية

الجهة: EISAX FZ-LLC  ·  الاختصاص القضائي: الإمارات العربية المتحدة  ·  آخر تحديث: سبتمبر 2026

تلتزم EISAX FZ-LLC («EISAX» أو «نحن») بالتعامل مع البيانات الشخصية بعناية وشفافية. توضح هذه السياسة كيفية تعاملنا مع المعلومات على موقعنا المؤسسي eisax.com، مع مراعاة مبادئ حماية البيانات المعمول بها في دولة الإمارات العربية المتحدة، بما فيها المرسوم بقانون اتحادي رقم 45 لسنة 2021 بشأن حماية البيانات الشخصية. يعكس هذا الإشعار ممارساتنا التشغيلية ومعاييرنا العامة لحوكمة البيانات.

1. النطاق والتطبيق

تسري سياسة الخصوصية هذه على البوابة المؤسسية الرسمية eisax.com والمواقع العامة ذات الصلة التي تديرها EISAX FZ-LLC مباشرة. قد تكون للمنتجات الفردية في منظومتنا، مثل WealthGate AI وEISAX Agent وSaveBuddy AI، إفصاحات خصوصية خاصة بها تتناول معالجة بيانات الحسابات.

2. المعلومات التي نجمعها

صُمم موقعنا المؤسسي بوصفه بوابة معلومات ثابتة تراعي الخصوصية. لا نطلب تسجيل حساب ولا نجمع بيانات تتبع متطفلة على هذا الموقع:

مرّر الجدول أفقيًا لعرض جميع الأعمدة.

المصدرعناصر البياناتالغرض والأساس القانوني
التواصل المباشرالاسم، والبريد الإلكتروني المهني، ونص الاستفسارالرد على استفسارات الأعمال أو المستثمرين أو الشراكات (الموافقة والمصلحة المشروعة).
التوزيع والحماية عبر الشبكة الطرفيةعنوان IP، وبيانات متصفح المستخدم، ووقت الطلب، والمُحيل عبر HTTPالتخفيف الآلي للتهديدات، ومنع هجمات حجب الخدمة، وتقديم المحتوى عبر Cloudflare Pages (المصلحة المشروعة).
المقاييس المجمّعةطلبات الصفحات، والمنطقة الجغرافية، ونوع الجهازمراقبة الأداء بصورة مجهولة الهوية ومن دون ملفات تعريف ارتباط أو إنشاء ملفات تعريف عبر المواقع.

3. ملفات تعريف الارتباط وتقنيات التتبع

لا نستخدم على eisax.com ملفات تعريف ارتباط تسويقية تابعة لأطراف ثالثة، أو وحدات تتبع لتصنيف السلوك، أو تقنيات تتبع عبر المواقع. نستخدم التخزين المحلي في المتصفح (localStorage) فقط لحفظ تفضيلك لمظهر الواجهة (الداكن أو الفاتح) واللغة المختارة (الإنجليزية أو العربية)، لاستمرار تجربة الاستخدام عبر الجلسات.

4. الاحتفاظ بالبيانات وأمنها

نطبق ضوابط إدارية ومادية وتقنية لحماية المراسلات المؤسسية والبنية التحتية:

  • التشفير: تُشفّر حركة البيانات أثناء النقل باستخدام TLS 1.3 مع سياسة صارمة لأمن النقل عبر HTTP‏ (HSTS).
  • التخزين: لا تُحتفظ بمراسلات الأعمال إلا للمدة اللازمة لتحقيق الغرض التشغيلي أو استيفاء المتطلبات القانونية.
  • أمن البنية التحتية: تستخدم الاستضافة الطرفية عزلاً بمستوى المؤسسات، وتصفية آلية لهجمات حجب الخدمة، وسياسات لأمن المحتوى.

5. حقوقك

وفقاً لمبادئ حماية البيانات المعمول بها في الإمارات والمعايير العامة لحوكمة البيانات، يمكنك:

  • طلب تأكيد بشأن معالجة معلوماتك الشخصية.
  • الوصول إلى بياناتك الشخصية أو تصحيحها أو طلب محوها.
  • تقييد أنشطة معالجة محددة أو الاعتراض عليها.
  • سحب موافقتك في أي وقت عندما تستند المعالجة إلى الموافقة.
